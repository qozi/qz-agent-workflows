# 任务表

这是本需求唯一细粒度状态来源。状态：待开始、进行中、待验收、已完成、阻塞、已取消。禁止使用“部分完成”；混合交付先拆分。

只由主 Agent 在主协调资料内更新。子 Agent 只读并回报结果，不复制本表到工作区，不直接修改状态。

任务批次归属仅在本表维护，批次目标和验收定义见需求 README；未开始的规划任务可写“待分配”，开始前必须关联一个已定义批次。一个任务跨多个独立批次时先拆分。
